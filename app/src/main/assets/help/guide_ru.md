# Руководство Z80 Pocket IDE

Практическая справка по основным функциям приложения. Выберите главу из оглавления. Справочник инструкций Z80 и системных адресов ZX Spectrum находится в отдельном пункте меню.

## 1. Начало работы и навигация

При первом запуске редактор открывается **без вкладок**. Нажмите большую кнопку «+» в центре, чтобы создать новый ASM-файл, либо воспользуйтесь **☰ → Файл → Открыть файл**. Сессия с ранее открытыми вкладками восстанавливается автоматически.

В верхней панели находятся быстрые команды: открыть файл/проект, сохранить, отменить/повторить изменение, поиск, инструменты и справочник «?». На узком экране панель можно прокручивать горизонтально. Кнопка **☰** справа открывает основное меню.

Основное меню разделено на **Файл**, **Проект**, **Правка**, **Сборка**, **Инструменты**, **Настройки**. Отдельные пункты ведут в **Руководство** (эта справка) и **Справочник Z80 / Spectrum** (инструкции и аппаратные сведения).

Полоса вкладок находится над кодом. Кнопка **INC** справа открывает подключаемые исходники; она выделяется зелёным, когда курсор стоит на строке с директивой INCLUDE. Круглая кнопка ▶ поверх редактора собирает и запускает TAP.

Нижняя строка состояния показывает сообщения о файле и сборке. Нажмите на неё, чтобы развернуть ошибки, размер кода и T-состояния.

## 2. Файлы, вкладки и сохранение

**☰ → Файл → Новый файл** создаёт пустую вкладку. **Открыть файл** позволяет выбрать ASM в системном файловом окне Android. Можно открыть несколько файлов: переключайтесь по вкладкам, нажимайте × для закрытия и удерживайте вкладку для команд сохранения и закрытия.

**Сохранить** записывает изменения в уже выбранный файл. Для новой вкладки откроется системное окно сохранения. **Сохранить как** создаёт новый файл с другим именем или в другом каталоге. Маркер ● возле имени означает несохранённые изменения. При закрытии изменённой вкладки приложение предложит сохранить или отбросить правки.

IDE проверяет изменения файлов извне при возвращении в приложение и примерно каждые 12 секунд, пока оно открыто. **Файл → Проверить внешние изменения** запускает проверку вручную. Если правок в открытой вкладке нет, содержимое обновляется автоматически. Если есть несохранённые правки, вкладка получает знак ↻, и IDE предлагает перечитать файл, сохранить локальную копию или оставить свои изменения; перед перезаписью внешнего файла появится подтверждение.

IDE хранит локальные **черновики, положение курсора и историю Undo/Redo** для восстановления после перезапуска. Это не замена сохранению на диск: удаление приложения или его данных удалит и локальные черновики.

Можно открыть ASM-файл через Android «Открыть с помощью», если файловый менеджер предоставляет подходящий тип файла. Если внешнему документу не хватает прав на запись, IDE предложит повторно выбрать этот же файл.

## 3. Редактор кода и управление

Редактор поддерживает **подсветку Z80**, номера строк, маркер текущей строки, автоматические отступы, подсказки имён меток и отмену/повтор правок. Строка в поле номеров выделяется нажатием; проведите по номерам, чтобы выделить несколько строк. Появившаяся внизу колонки кнопка × снимает выделение.

**Одним пальцем** можно прокручивать код для чтения, не перенося курсор; курсор устанавливается точным нажатием. **Двумя пальцами** меняется масштаб шрифта, который затем запоминается.

Над системной клавиатурой находится компактная панель: TAB, быстрые символы (в том числе кавычки, ;, :, #, $, скобки) и подсказки меток. Кнопка TAB работает как с символом табуляции, так и с пробелами — в зависимости от настроек.

У текущей инструкции редактор может показывать объём в байтах и длительность в **T-состояниях**. Размер и число T-состояний для выделенных строк или всего исходника доступны в развёрнутой панели состояния.

## 4. Поиск, замена и форматирование

Нажмите значок лупы либо **☰ → Правка → Найти / Заменить**. Введите текст, используйте стрелки перехода по найденным совпадениям, переключайте **Aa** для чувствительности к регистру. Можно заменить одно совпадение либо сразу все.

**Правка → Форматировать код** приводит документ к выбранному стилю отступов и ключевых слов. **Правка → Весь код заглавными** изменяет весь текст, включая имена меток, строки и комментарии: используйте осторожно.

Ошибки компиляции отмечаются и показываются внизу редактора. Если ошибка относится к текущему файлу, можно перейти к её строке.

## 5. Проекты, INCLUDE и INCBIN

Для проекта из нескольких исходников выберите **☰ → Проект → Открыть проект** и укажите папку через системный выбор каталогов Android. Приложение получит доступ к файлам внутри выбранной папки.

Пункт **Проект → Главный ASM: имя_файла** открывает выбор главного исходника. Именно он является точкой входа для сборки проекта. **Настройки проекта** позволяют задать имя проекта, главный ASM и параметры загрузочной заставки.

Директива INCLUDE подставляет текст другого исходника:

```asm
INCLUDE "lib/sprites.asm"
```

**INC** на полосе вкладок и **Файл → Открыть INCLUDE** помогают открыть подключаемый файл для редактирования. INCLUDE-пути разрешаются относительно включающего ASM-файла.

Директива INCBIN вставляет **двоичные данные без преобразований**:

```asm
SPRITE: INCBIN "assets/ship.bin"
INCBIN "assets/title.scr", 6144, 768
```

Необязательные аргументы задают смещение и длину (в байтах). INCBIN ищет ресурс относительно ASM-файла, где написана директива. Для файлов из папки проекта нужен разрешённый доступ к этой папке. Проверяйте сообщения о неверном пути, длине файла и превышении лимитов.

## 6. Ассемблер и первый пример

В IDE встроен двухпроходный ассемблер Z80. Он поддерживает инструкции процессора, выражения и метки, основные директивы **ORG, EQU, DB/DEFB, DW, DS**, макросы и условную сборку, а также **ASSERT** для проверки условий при сборке.

Пример короткой программы:

```asm
ORG $8000

START:
    LD A,2
    OUT ($FE),A
    RET
```

Нажмите **Сборка → Собрать проект**. При успешной сборке строка состояния покажет объём кода и адрес ORG, а TAP будет подготовлен для сохранения или запуска.

Для больших проектов используйте разные файлы с INCLUDE и фиксируйте предположения командой ASSERT, например:

```asm
ASSERT END_CODE - START <= 16384, "Code too large"
```

Ассемблер сообщает об ошибках вместе с номером строки. При ошибке во включённом файле проверяйте путь и номер строки в диагностике.

## 7. Сборка, TAP и запуск эмулятора

**☰ → Сборка → Собрать проект** собирает исходный ASM и готовит TAP с BASIC-загрузчиком. **Собрать и запустить** делает сборку и передаёт TAP установленному приложению-эмулятору. То же действие выполняет круглая кнопка ▶ поверх редактора.

**Сборка → Экспорт SNA 48K** создаёт снимок оперативной памяти Spectrum (49179 байт). Системный файловый пикер предлагает выбрать имя и место сохранения файла .sna. В отличие от TAP, SNA запускает код **непосредственно по адресу ORG** без BASIC-загрузчика и использует SCREEN$ из проекта, если она задана. Задержка заставки из настроек проекта на SNA не влияет. Экспорт возможен только для кода, размещённого в RAM от $4000 до $FFFF; пересечение кода с SCREEN$ запрещено. Регистр SP задаётся экспортёром, PC передаётся через стек. Программа должна сама инициализировать необходимые системные переменные и аппаратное состояние. При сборке на кнопке ▶ появляется вращающийся индикатор.

**Сборка → Экспорт TAP** предлагает выбрать место для сохранения результата через Android. Для запуска TAP нужен отдельный установленный эмулятор ZX Spectrum, способный открывать такие файлы.

Если на устройстве несколько эмуляторов, задайте нужный через **☰ → Настройки → Эмулятор TAP**. При отсутствии подходящего приложения Android может показать сообщение о невозможности открыть TAP.

Если сборка не проходит, раскройте нижнюю панель ошибок, исправьте исходник и выполните сборку повторно. Сохранение ASM и экспорт TAP — **разные операции**: экспорт игры не сохраняет автоматически текст исходника.

## 8. Редактор экранов ZX Spectrum

Откройте **☰ → Инструменты → Редактор экранов** либо вкладку **Экран** в инструментах Z80. Редактор работает с SCREEN$: **256×192 точки**, **6144 байта изображения + 768 байт атрибутов** (всего 6912 байт).

На плавающей палитре выбирают **перо (INK), ластик (PAPER), пипетку**, цвета и флаги BRIGHT/FLASH. Для рисования снимите **замок**; при включённом замке доступен безопасный просмотр и перемещение холста. Доступны масштабирование, перемещение и отмена/повтор.

**Выделение:** отметьте прямоугольник, нажмите Копия, перейдите к другому месту или экрану и выберите Вставить. Стрелки сдвигают область на один пиксель; **✓** подтверждает перемещение, **×** отменяет. Флажок **Сдвиг атр. 8px** управляет переносом атрибутов целыми знакоместами (по восемь пикселей).

Экран можно открыть или сохранить как **.scr / .bin**; доступен также экспорт данных в **.asm**, включая варианты RLE. При работе с файлами проверяйте размер и не забывайте нажимать «Сохранить».

## 9. Инструменты, примеры и справочник

Выберите **☰ → Инструменты → Калькулятор / Адреса / Спрайты** либо кнопку инструментов вверху. Откроется окно с пятью вкладками:

- **123** — перевод числа между DEC, HEX и BIN.
- **Адреса** — расчёт адресов bitmap/атрибутов по координатам ZX Spectrum.
- **Спрайт** — рисование спрайта и маски, сдвиг и обмен данными в формате DB.
- **Клавиши** — матрица клавиатуры Spectrum и примеры чтения портов.
- **Экран** — встроенный редактор SCREEN$ с переходом в полноэкранный режим.

**Инструменты → Примеры и подпрограммы** открывает библиотеку. Выберите пример, прочитайте описание, запустите его отдельно либо откройте в редакторе **с комментариями или без**.

**Справочник Z80 / Spectrum** — отдельная техническая база по инструкциям, флагам, T-состояниям, памяти, ROM и портам ZX 48K. Это руководство описывает действия пользователя, а справочник — аппаратные и машинные детали.

## 10. Настройки приложения и проекта

Через **☰ → Настройки → Настройки редактора** меняют автоматический верхний регистр, отступы, ширину TAB (2/4/8), пробелы вместо табуляции, панель быстрых символов и подсказки меток.

Пункт **Язык интерфейса: RU/EN** переключает язык приложения сразу после нажатия. Настройка запоминается; отдельный языковой пакет скачивать не нужно.

В **Настройках проекта** можно выбрать заставку из файла .scr/.bin и задержку запуска игры: сразу, через несколько секунд либо до нажатия клавиши. При включённой заставке она добавляется в TAP перед кодом игры. Проектные параметры сохраняются в файле **.z80pocketide.json** внутри проекта, если файловый провайдер разрешает запись; иначе используется локальная копия.

**Настройки → Эмулятор TAP** открывает выбор Android-приложения для запуска TAP.

## 11. Частые вопросы и сохранность данных

**Не вижу вкладок при запуске.** Это нормально для новой или полностью закрытой сессии. Нажмите «+» в центре или откройте ASM/проект через меню.

**INC не светится.** Активная подсветка появляется только на строке с корректной директивой INCLUDE. Кнопка остаётся доступной и на других строках, если открыт исходник.

**Не найден INCLUDE/INCBIN.** Проверьте относительный путь, имя файла, регистр в имени и доступ Android к папке проекта.

**TAP не запускается.** Установите совместимый эмулятор и выберите его в настройках TAP.

**Файл не сохраняется.** Проверьте права записи у Android-провайдера документа; при необходимости повторно выберите исходный файл.

**Где находятся черновики?** Во внутреннем хранилище приложения. Они помогают восстановить сессию, но **не заменяют сохранённые ASM и SCR файлы**. Перед удалением приложения, очисткой данных или сменой сборки сохраните нужные проекты отдельно.
