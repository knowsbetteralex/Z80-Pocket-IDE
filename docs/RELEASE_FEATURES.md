# Current release highlights / Краткое описание текущего релиза

Update both sections when preparing each new app version. CI copies these bullets
into GitHub Release notes. Full technical history stays in CHANGELOG.md.

## Русский

- Пункт «Открыть Git-проект» показывает доступные репозитории после входа с ограниченным GitHub-токеном.
- Одна команда Pull + Push получает и отправляет изменения без локальных Git-коммитов.
- При конфликте можно оставить свою версию, взять GitHub или объединить текст вручную.

## English

- Open Git project lists accessible repositories after connecting a limited-access GitHub token.
- One-tap Pull + Push retrieves and uploads changes without local Git commits.
- Conflicts can be resolved by keeping the local file, using GitHub, or merging text manually.
