# Current release highlights / Краткое описание текущего релиза

Update both sections when preparing each new app version. CI copies these bullets
into GitHub Release notes. Full technical history stays in CHANGELOG.md.

## Русский

- Колокольчик слева от меню показывает красную точку при выходе нового непросмотренного релиза.
- Нажатие открывает окно с новыми возможностями и ссылкой на релиз GitHub.
- Проверка обновлений работает в фоне; прочитанные уведомления запоминаются.

## English

- The update bell left of the menu shows a red dot for an unread new release.
- Tap it to see what's new and open the release page on GitHub.
- Release checks run in the background, and read notifications stay dismissed.
