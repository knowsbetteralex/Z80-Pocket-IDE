# Current release highlights / Краткое описание текущего релиза

Update both sections when preparing each new app version. CI copies these bullets
into GitHub Release notes. Full technical history stays in CHANGELOG.md.

## Русский

- Колокольчик появляется только при наличии более нового релиза GitHub и исчезает после установки соответствующей или более новой версии.
- Просмотр описания релиза больше не скрывает уведомление — оно остаётся до обновления приложения.
- Заголовок окна обновления: «Доступен новый релиз». Подробности и ссылка на GitHub доступны на выбранном языке.

## English

- The update bell appears only when a newer GitHub release is available and disappears once that version or a newer one is installed.
- Viewing release notes no longer dismisses the update indicator: it stays visible until the app is upgraded.
- The dialog now says “New release available”, with localized feature notes and a GitHub release link.
