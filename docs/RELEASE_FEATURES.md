## Русский

- Анимация ожидания сборки теперь видна внутри кнопки запуска.
- Git Sync открывает авторизацию или выбор репозитория даже до подключения проекта.
- Автокапитализация сохраняет регистр внутри строк, двойная кавычка автоматически создаёт пару с курсором внутри.

## English

- The build spinner is now visible above the Run button during compilation.
- Git Sync opens account sign-in or repository selection even before a project is connected.
- Auto-uppercase leaves quoted strings unchanged; typing a double quote inserts a pair with the cursor inside.
